# Graficos - Angular

Aplicacion web de graficos realizada con Angular, Material Design, Bootstrap utilizando [charts.js](https://www.chartjs.org/).

## Instalar dependencias
- Ejecutar en terminal comando: `pnpm install`.

## Iniciar proyecto
Ejecutar en terminal el comando `pnpm start` e introducir en el navegador `http://localhost:4200/`.

## Scripts disponibles
- `pnpm start` - levanta el servidor de desarrollo (`ng serve`).
- `pnpm run build` - compila la aplicación para producción.
- `pnpm test` - ejecuta los tests unitarios (Vitest).
- `pnpm run lint` - ejecuta ESLint sobre el proyecto.

## Ayuda
Para mas informacion, ejecutar el comando `pnpm exec ng help` en el terminal o ir a [Angular CLI README](https://github.com/angular/angular-cli/blob/master/README.md).
Este proyecto utiliza [Angular CLI](https://github.com/angular/angular-cli) version 22.
